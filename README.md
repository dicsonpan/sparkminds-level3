# 创智实验室 Level 3 三部曲 · 家长课程页

创智实验室（SparkMinds）Level 3 三期课程的家长版课程介绍静态页，部署于 Cloudflare Pages。

- `index.html` → 第一部 · 基础期 · **TurtleFlight 会飞的海龟**（3D 代码造物）
- `beetlebrain.html` → 第二部 · 实践期 · **BeetleBrain 会思考的甲虫**（Mind+ × Arduino 硬件编程）
- `beetlebot.html` → 第三部 · 进阶期 · **BeetleBot 活过来的甲虫**（3D 身体 × Arduino 大脑融合项目）

每期 15 次课 × 2 小时，三部曲递进。更多内容见官网 [sparkminds.cn](https://sparkminds.cn)。
